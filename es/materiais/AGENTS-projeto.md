# Instrucciones del proyecto de entrenamiento

1. Lea README.md y liste las fuentes disponibles antes de modificar.
2. Use solo entradas/ y saidas/ para esta tarea. No lea .env.
3. No invente datos faltantes: describa la pendiente.
4. Compare los totales con los valores de entrada antes de entregar.
5. Reporte archivos modificados, verificación ejecutada y resultado observado.
6. No envíe ni publique resultados sin una instrucción explícita.

Consulte ../config/memoria.md y ../config/decisoes.md solo cuando sean relevantes.
Las reglas orientan el comportamiento; mantenga también permisos técnicos adecuados.
