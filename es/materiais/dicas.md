# Consejos verificados

## Inspeccionar cambios
Use git status para ver archivos modificados y git diff para diferencias no preparadas.

## Consultar registros de un servicio
Use journalctl -u NOMBRE-DEL-SERVICIO -n 50 --no-pager en sistemas con systemd.
Reemplace el nombre y confirme que está en la máquina correcta.

Registre fecha y entorno al añadir un procedimiento.
