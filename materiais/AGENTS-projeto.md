# Instruções do projeto de treino

1. Leia README.md e liste as fontes disponíveis antes de alterar.
2. Use apenas entradas/ e saidas/ para esta tarefa. Não leia .env.
3. Não invente dados faltantes: descreva a pendência.
4. Compare os totais com os valores de entrada antes de entregar.
5. Relate arquivos alterados, verificação executada e resultado observado.
6. Não envie nem publique resultados sem uma instrução explícita.

Consulte ../config/memoria.md e ../config/decisoes.md somente quando forem relevantes.
As regras orientam comportamento; mantenha também permissões técnicas adequadas.
