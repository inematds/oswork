# Dicas verificadas

## Inspecionar alterações
Use git status para ver arquivos modificados e git diff para diferenças não preparadas.

## Consultar logs de um serviço
Use journalctl -u NOME-DO-SERVICO -n 50 --no-pager em sistemas com systemd.
Substitua o nome e confirme que está na máquina certa.

Registre data e ambiente ao acrescentar um procedimento.
