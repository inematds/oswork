# Meu primeiro projeto OSWork

## Propósito
Produzir relatórios de treino a partir de dados fictícios.

## Leia primeiro
1. AGENTS.md
2. entradas/vendas.csv
3. ../config/decisoes.md, se existir e for relevante.

## Organização
- entradas/: fontes de treino, sem dados pessoais.
- saidas/: rascunhos revisáveis.
- AGENTS.md: instruções de execução.

## Como verificar
Compare os totais com as entradas. Marque valores ausentes como pendências.
